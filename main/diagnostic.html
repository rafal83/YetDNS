Ce que mesure le test

Une sonde utilise une requête HTTPS HEAD sans cookies ; le navigateur suit les redirections HTTPS éventuelles. Aucun contenu de page n’est affiché ou exécuté. Les tests de sécurité utilisent des domaines témoins synthétiques.

Une réponse HTTP prouve que l’hôte est joignable. Un échec ne prouve pas un blocage DNS : extension, certificat, serveur indisponible, VPN, pare-feu ou restriction du navigateur peuvent produire le même résultat. Le rapport indique donc un filtrage apparent, jamais une certification de sécurité.

Le navigateur ne révèle pas les réponses DNS brutes, le résolveur utilisé, la couverture A/AAAA ni le SafeSearch imposé. Le DNS sécurisé du navigateur et ses caches peuvent différer de ceux du système. Les domaines testés voient les sondes et l’IP de sortie ; les résultats ne sont pas envoyés à l’ESP ni à un service de test.
