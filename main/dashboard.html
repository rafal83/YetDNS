Protection du réseau

Listes de blocage et mises à jour

Choisissez les listes prédéfinies ou ajoutez vos URL HTTPS. Les doublons sont fusionnés. Formats : domaines, hosts, règles simples ||domaine^.

Lecture de l’état des listes…

La liste précédente reste active si un téléchargement échoue. Les exceptions gardent la priorité sur les listes.

Paramètres avancés

En mode DoH, une panne HTTPS ne provoque aucun repli en clair. Les changements s’appliquent aux nouvelles requêtes ; le cache local est vidé.

Home Assistant · MQTT

La découverte automatique crée un appareil YetDNS avec ses capteurs, interrupteurs et boutons dans Home Assistant.

Intégration non configurée.

Le broker doit être le même que celui de l’intégration MQTT de Home Assistant. Les noms des domaines consultés restent sur l’ESP et ne sont pas publiés dans MQTT.

Règles locales par appareil

32 règles persistantes maximum. Une règle avec client s’applique uniquement à cette adresse IPv4 et passe avant les règles globales. Sans client, elle concerne tous les appareils. Le domaine et ses sous-domaines sont concernés ; le suffixe le plus précis gagne dans chaque groupe.

Exemple : des règles pour l’appareil 192.168.1.50

Pour cet appareil uniquement : bloquer YouTube (deny), autoriser un domaine malgré les listes (allow) et faire pointer nas.home.arpa vers un NAS (rewrite).

[
  {"domain":"youtube.com","action":"deny","client":"192.168.1.50"},
  {"domain":"pagead2.googlesyndication.com","action":"allow","client":"192.168.1.50"},
  {"domain":"nas.home.arpa","action":"rewrite","client":"192.168.1.50","address":"192.168.1.10"}
]

Remplacez les IP et domaines, puis ajoutez les objets souhaités au tableau JSON ci-dessous en conservant vos règles existantes. Cet exemple n’est pas appliqué automatiquement. Réservez l’IP de l’appareil dans le DHCP du routeur.

L’appareil doit interroger directement l’ESP comme serveur DNS. Si le routeur relaie toutes les requêtes avec sa propre IP, YetDNS ne peut pas distinguer les appareils. Le journal permet de vérifier l’IP réellement reçue. Bloquer youtube.com seul ne couvre pas tous les domaines utilisés par le service.
